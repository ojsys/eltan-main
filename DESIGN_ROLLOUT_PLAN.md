## 📐 Design Principles

All redesigned pages will follow:

1. **Material Design 3**
   - Elevation shadows
   - Rounded corners
   - Consistent spacing
   - Material icons

2. **ELTAN Brand Colors**
   - Primary: Orange (#E67918)
   - Secondary: Blue (#1565C0)
   - Accent: Teal (#00796B)
   - Grays for text/backgrounds

3. **Typography**
   - Poppins font family
   - Clear hierarchy
   - Readable line heights
   - Responsive font sizes

4. **Responsive Design**
   - Mobile-first approach
   - Breakpoints: 640px, 1024px
   - Touch-friendly targets
   - Optimized images

5. **Accessibility**
   - WCAG 2.1 AA compliance
   - Keyboard navigation
   - Screen reader support
   - Color contrast ratios

6. **Performance**
   - Fast loading times
   - Optimized images
   - Minimal JavaScript
   - CSS-only animations where possible
